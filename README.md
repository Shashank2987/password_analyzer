# Password Strength Analyzer

A Flask web app that analyzes password strength using a trained machine learning model (with a transparent heuristic fallback when the model isn't available).

## Features

- **ML-based classification** — a char-level TF-IDF + LinearSVC model predicts password strength.
- **Heuristic fallback** — if the trained model files aren't present, the app automatically falls back to an entropy/composition-based classifier so it still works out of the box.
- **Entropy estimation** — calculates password entropy based on the character sets used (lowercase, uppercase, digits, special characters).
- **Crack time estimate** — estimates average brute-force crack time at 1 billion guesses/second.
- **Character breakdown** — reports length and counts of uppercase, lowercase, digit, and special characters.
- **Actionable suggestions** — flags common passwords and suggests concrete improvements.

```bash
pip install flask pandas scikit-learn joblib
```

## Usage

### 1. Train the model (optional)

If you want to (re)generate `password_strength_model.pkl` and `label_encoder.pkl` from the dataset:

```bash
python trainer.py
```

This reads `trainer_dataset.csv`, trains a TF-IDF + LinearSVC pipeline, prints accuracy/classification report, and saves the model and label encoder to disk.

### 2. Run the app

```bash
python app.py
```

The app starts on `http://localhost:5000`.

- If `password_strength_model.pkl` and `label_encoder.pkl` are present in the working directory, the app loads and uses the trained ML model.
- Otherwise, it prints a warning and uses a built-in heuristic classifier instead, so the app remains fully functional without the model files.

### 3. API

**POST** `/api/analyze`

Request body:
```json
{ "password": "example123!" }
```

Response:
```json
{
  "strength": "Fair",
  "entropy": 45.2,
  "crack_time": "3.14 years",
  "analysis": {
    "Length": 11,
    "Uppercase": 0,
    "Lowercase": 7,
    "Digits": 3,
    "Special Characters": 1
  },
  "suggestions": ["Add uppercase letters."],
  "using_ml_model": true
}
```

## Notes

- The dataset labels each password as `strong password` or `weak password`; `label_encoder.pkl` maps these to the numeric classes used internally by the model.
- `templates/index.html` is referenced by `app.py` but not included in this upload — add your own template or a minimal HTML form that posts to `/api/analyze`.
- Entropy and crack-time estimates are simplified approximations for educational purposes and shouldn't be treated as precise security guarantees.
